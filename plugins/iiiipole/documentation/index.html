User guide

Ullhexa IIIIPole Getting Started Insert Ullhexa IIIIPole on an audio or instrument channel. Start with low monitoring volume, FB at zero and a modest resonance setting. Open the Ull Hexa logo for About, UI Controls and Scaling options. The built-in UI Controls page contains the full editing and routing reference. Filter CUTOFF sets the low-pass frequency. RESONANCE emphasizes the cutoff region; RES SPLIT separates the resonance peaks. DRIVE adds saturation with managed level. SRR reduces the input sample rate for stepped textures, and HP removes low frequencies. Yellow switches enable each effect independently of its knob. TRIM adjusts input level. WET/DRY blends processed and dry audio; OUT controls both. Higher oversampling settings increase the ladder core's integration rate and use more CPU. Oversampling does not make a highly nonlinear effect alias-free. The knob pointer is the set position. The white value arc follows modulation, and colored outer arcs show modulation ranges. Cutoff also shows the MIDI pitch offset. Knob images do not move with modulation. Feedback Caution FB returns up to 100% of the protected wet signal before SRR and DRIVE. WET/DRY and OUT remain outside this loop. With any FB above zero, RESONANCE and RES SPLIT use half their ordinary ranges and DRIVE is limited to 20 dB instead of 30 dB. Purple indicators identify these reduced ranges; knob travel remains unchanged. At zero FB, normal ranges return. Feedback and high resonance can produce unwanted, loud sustained tones. These limits do not eliminate the risk. Keep monitoring volume low and raise FB gradually. Double-click FB to reset it to zero. MIDI Create a separate MIDI track and route it to IIIIPole on the channel hosting the plugin. Some DAWs can route an instrument track's MIDI directly to insert effects instead. Follow the host's routing instructions. The AU is a MIDI-capable music effect, not a standalone instrument. - v/oct follows the last note; MIDI note 60 is the reference. DAWs may label its octave differently. - retrig restarts all four curves on a fresh note and loops while notes are held. Overlapping notes continue the current progression. After release, each curve finishes its cycle and holds its endpoint. Sustain also holds the gate. - velo opens cutoff by up to one third of its range. Pitch and velocity latch until the next note. With retrig off, tempo and Hz modes run freely. Trig mode still responds to fresh notes, plays once and holds the endpoint. Release all notes before triggering again. Selecting a Time mode does not change retrig. Modulation MOD opens the second panel. Buttons 1-4 select the edited curve; the diodes above them enable background views. The active curve is always visible. CLONE arms copying to another page; select a pulsing destination or cancel by pressing CLONE again or elsewhere. Double-click to add a node or remove a free node. White edge nodes are linked. Drag between nodes to bend a segment. The grid number sets 1-16 time divisions: drag, scroll, or double-click to type. Its diode toggles snapping; Shift bypasses snapping. With the curve focused, Cmd/Ctrl+C and Cmd/Ctrl+V copy and paste nodes. TIME offers Straight, Dotted, Triplet, Hz and Trig. Hz covers 0.005-200 Hz; Trig covers 5 ms-25 s. LOG/LIN/EXP shapes interpolation. SKEW tapers either side toward the vertical midpoint. LEVEL changes the amplitude span. The right-hand slider offsets the curve, stopping nodes at the display limits. Controller changes are reversible by restoring their settings; manual node editing adopts the displayed shape as the new source. Signed faders set destination depths. Cutoff can combine all four sources; other destinations use one. UNI sends in one direction; BI sends around the set value. ON/OFF bypasses individual sends, and the bottom button bypasses all modulation. The white fader diode toggles center snapping. Curves And Presets The left triangle opens the curve library. Click a shape to apply it and close the library, or use the small arrows to step through the chosen Factory/User list. Editing never switches categories. One custom draft per page appears in User with an exclamation mark; S or Save adds it to the library. Selecting another shape retains that draft, but editing another replaces it. Delete opens multi-selection and requires confirmation. Factory shapes cannot be deleted. While browsing, the right-hand slider scrolls instead of changing offset. The preset bar stores the plugin settings, curves, custom drafts, selected mod page and visibility choices. It excludes input trim, wet/dry, oversampling, panel-open state and UI scale. Preset browsing stays open for auditioning. Save As creates a user preset; Rename and Delete apply only to user presets. Preset operations do not save or delete library curves. Enter confirms text; Escape cancels. DAW projects also retain unsaved custom curves. Scaling And Files Choose a scale in the Ull Hexa menu or drag the bottom-right corner. The same instance remembers its size when reopened. Set current scaling to Default sets the initial size for new instances. User presets, curves and default UI settings are stored in ~/Library/Application Support/Ull Hexa/IIIIPole. Keep backups of important sessions and user files.
